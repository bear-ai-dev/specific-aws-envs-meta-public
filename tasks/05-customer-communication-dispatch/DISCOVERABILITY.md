# Discoverability

One row per rule that can change the verdict. Every rule has to be knowable
from `instruction.md`, from code the agent can read in `/app`, or from data the
agent can read or query on the box. Paths below are the container's:
`/app` is the workspace, `/opt/meteringco-mail-sandbox` is the sandbox account and
the staging capture that came with it.

The capture is two files, paired only by their order:

    /opt/meteringco-mail-sandbox/dispatch-capture/communication-events.jsonl
    /opt/meteringco-mail-sandbox/dispatch-capture/ses-outbox.jsonl

Ten communications went onto the bus during the captured window and seven
messages came out of it, so the file lengths themselves say that some events
put nothing on the wire. Both files are generated by `gen_scenarios.py` from
the same `framing()` function that `tests/compute_reward.py` re-implements, so
the evidence in the box and the answer the grader derives cannot drift apart.

## Rules that are not graded

- Which AWS region the client is built with. The endpoint is fixed by
  `AWS_ENDPOINT_URL` and the outbox records nothing about region.
- Whether the empty `cc`/`bcc` lists are sent explicitly or left off. An empty
  list and an absent one are indistinguishable on this wire protocol and
  `compute_reward.py` normalises both to `[]`.
- Message ids, timestamps, logging, audit events, return values, exit codes,
  and anything else the submission chooses to do around the send.
- Where the processor is wired from. The driver tries a module lifecycle hook,
  a `subscribe`-shaped method on `CustomerService`, and import side effects,
  and if none of those has left a listener on the channel it subscribes the
  dispatcher it finds itself.

## Nothing in the workspace points the other way

`rg -l "UTF-8|SendEmail|SESClient|ConfigurationSet|ReplyTo"` over the workspace,
excluding `package-lock.json`, the bundled Redoc HTML under `docs/` and the
vendored `.proto` files, returns nothing. No helper left in the tree frames a
mail header, so there is no in-repo convention competing with the captured one.
